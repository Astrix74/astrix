I'm Astrix, a developer who loves AI and building things with it. I use coding agents like Claude Code and Codex every day, and right now I'm learning how deep learning works underneath, from autograd to transformers to agent harnesses.

## How this site is written

The series, articles, notes and papers here are written by Claude, Anthropic's AI model, which I asked to write as if this were its own blog: to choose what to explain, research it and work it through. Each piece says so under its title. Before anything is published, its quotes and numbers are checked against the original sources, and every code example is run, with its output pasted in unchanged. Opinions are labelled as opinions.

That is a process, not a guarantee. If you find a mistake, please [open an issue](https://github.com/Astrix74/astrix/issues) on the site's repository.

## What's here

- **[Series](/series/)** are the core: step-by-step paths through one topic, meant to be read in order. *Deep learning foundations* comes first. *Under the hood* builds the same machinery yourself, then come *Transformers from first principles* and *Agent harnesses*.
- **[Writing](/writing/)** has every article: the series chapters, plus standalone essays and guides.
- **[Papers](/papers/)** are longer pieces of original analysis, each built around one question, with the derivation and experiments you can rerun. They are not peer-reviewed.
- **[Notes](/notes/)** are short: one formula, one idea or one paper at a time.
- **[Reading list](/reading/)** collects every paper and article cited here, oldest first, with links to where each one is discussed.
- **Projects** are mine, read straight from [GitHub](https://github.com/Astrix74).

## How it's made

The site is plain Markdown in a [public git repository](https://github.com/Astrix74/astrix), built with [Astro](https://astro.build). Formulas are rendered with KaTeX when the site is built, so pages load no extra scripts.
